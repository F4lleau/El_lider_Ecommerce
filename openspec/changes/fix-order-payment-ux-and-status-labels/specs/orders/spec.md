# Order UX and Labels Spec Delta ## ADDED Requirements ### Requirement: Order tracking code is shown as user-friendly follow-up code The system SHALL display tracking codes using user-friendly Spanish labels. #### Scenario: Guest order confirmation Given a guest order is created When the confirmation page is displayed Then the tracking code is shown as `Número de seguimiento` or `Código de seguimiento` And the user is told to save it to check order status. --- ### Requirement: Order statuses are displayed in Spanish The system SHALL display order statuses in Spanish in all user-facing and admin-facing screens. #### Scenario: Pending payment order Given an order has status `PENDING_PAYMENT` When the order is displayed Then the UI shows `Pendiente de pago`. #### Scenario: Confirmed order Given an order has status `CONFIRMED` When the order is displayed Then the UI shows `Pedido confirmado`. --- ### Requirement: Delivery-specific order states are shown The system SHALL show status options and labels according to the delivery method. #### Scenario: Pickup order status options Given an order has delivery method `PICKUP` When admin changes order status Then pickup-related states are shown. #### Scenario: Shipping order status options Given an order has delivery method `SHIPPING` When admin changes order status Then shipping-related states are shown. --- ### Requirement: Payment and delivery methods are displayed in Spanish The system SHALL display payment and delivery methods in Spanish. #### Scenario: Cash payment Given an order has payment method `CASH` When it is displayed Then the UI shows `Efectivo`. #### Scenario: Mercado Pago payment Given an order has payment method `MERCADOPAGO` When it is displayed Then the UI shows `Mercado Pago`. #### Scenario: Pickup delivery Given an order has delivery method `PICKUP` When it is displayed Then the UI shows `Retiro en sucursal`. #### Scenario: Shipping delivery Given an order has delivery method `SHIPPING` When it is displayed Then the UI shows `Envío a domicilio`.
